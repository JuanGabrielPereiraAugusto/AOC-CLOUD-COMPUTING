## 🕰️ Surgimento

| Ano | Marco |
|---|---|
| **Anos 1960** | John McCarthy prevê a computação oferecida como um serviço público, como a energia elétrica |
| **Meados dos anos 2000** | O termo *cloud computing* se populariza |
| **2006** | A Amazon lança o **AWS**, ponto de virada dos serviços em nuvem |

A nuvem é a evolução natural da **virtualização**, das **redes** e dos **serviços distribuídos**.

---

## ✨ Características

- **Elasticidade:** os recursos aumentam ou diminuem conforme a demanda
- **Pagamento sob demanda:** paga só pelo que usa
- **Acesso remoto:** de qualquer lugar com internet
- **Recursos compartilhados:** infraestrutura dividida entre usuários, de forma isolada
- **Automatização:** distribuição e gerenciamento automáticos

## 🔒 Segurança

**Criptografia** (dados em trânsito e em repouso) · **controle de acesso** · **redundância** · **backups automáticos** · **certificações** (ISO 27001, GDPR, LGPD)

A segurança também depende do usuário: senhas fortes e políticas de acesso adequadas.

## 🏗️ Arquitetura

### Modelos de serviço

| Camada | O que oferece | Exemplos |
|---|---|---|
| **IaaS** (Infraestrutura) | Servidores, armazenamento e redes | AWS EC2, Microsoft Azure |
| **PaaS** (Plataforma) | Ambiente de desenvolvimento, bibliotecas e bancos de dados | Google App Engine, Heroku |
| **SaaS** (Software) | Aplicação pronta, usada pelo navegador | Gmail, Microsoft 365 |

### Modelos de implantação

| Tipo | Como funciona |
|---|---|
| **Pública** | Infraestrutura compartilhada entre vários clientes (ex.: Google Cloud) |
| **Privada** | Infraestrutura dedicada a uma única organização |
| **Híbrida** | Combinação das duas, com mais flexibilidade |

## ⚖️ Vantagens e desvantagens

| ✅ Vantagens | ❌ Desvantagens |
|---|---|
| Redução de custos com infraestrutura física | Depende de conexão com a internet |
| Escalabilidade | Preocupações com a privacidade dos dados |
| Mobilidade e acesso remoto | Possíveis custos ocultos |
| Atualizações automáticas pelo provedor | Menor controle sobre a infraestrutura |
| Alta disponibilidade | |
